# 예썰 — 영상 기승전결 템플릿 v1
> 모든 영상은 이 흐름으로 전개된다. 소재가 바뀌어도 뼈대는 같다.

---

## 핵심 원칙

> **시청자는 답을 알고 싶어서 클릭한 게 아니다.**
> **자신의 생각이 맞는지 확인하러 클릭한다.**
> 그래서 영상은 항상 시청자의 통념을 건드리는 것에서 시작해야 한다.

---

## 기승전결 구조

```
기 (起) — 도발      : 시청자의 통념을 흔든다
승 (承) — 근거      : 우리 프레임으로 사건을 재해석한다
전 (轉) — 반전      : 시청자가 예상 못 한 결정타를 날린다
결 (結) — 판결      : 단호하게 티어를 선고한다
```

---

## 기 (起) — 도발 / 0:00 ~ 1:00

**목적** : 시청자의 통념을 흔들어 "어? 왜?"를 만든다

**공식**
```
"대부분의 사람들은 [예능인/상황]을 [일반적인 시각]으로 본다.
 하지만 오늘 저는 다르게 말씀드리겠습니다.
 [핵심 주장 — 도발적으로]"
```

**예시**
```
"많은 분들이 정준하를 그냥 맞는 캐릭터, 
 무한도전의 들러리라고 생각합니다.
 하지만 저는 정준하야말로 무한도전의 진짜 MVP라고 생각합니다."
```

**체크포인트**
- [ ] 시청자가 알고 있는 통념을 먼저 꺼냈는가
- [ ] 핵심 주장이 도발적으로 던져졌는가
- [ ] 15초 안에 주장이 나왔는가

---

## 승 (承) — 근거 쌓기 / 1:00 ~ 5:00

**목적** : 우리만의 프레임(유형/포지션)으로 장면을 재해석해 주장을 뒷받침한다

**공식**
```
"[예능인]의 유형은 [유형]형입니다. 쉽게 말해 [비유]입니다.
 포지션은 [포지션]. [포지션 정의]하는 역할이죠.
 
 [장면 1] — 이 장면을 보면 [분석 포인트]
 [장면 2] — 여기서 [예능인]이 한 행동은 사실 [재해석]
 [장면 3] — 그리고 결정적으로 [핵심 근거]"
```

**핵심 포인트**
- 장면을 보여줄 때 "재밌었다"가 아니라 **"왜 재밌었는지"** 를 분석
- 시청자가 그냥 지나쳤던 장면을 **새롭게 보게** 만드는 것이 목표
- 근거는 최소 2개, 최대 3개. 그 이상은 지루해진다

**체크포인트**
- [ ] 유형 + 포지션 프레임으로 장면을 설명했는가
- [ ] "재밌다"가 아닌 "왜 재밌는가"를 설명했는가
- [ ] 시청자가 몰랐던 시각을 제공했는가

---

## 전 (轉) — 반전 / 5:00 ~ 7:00

**목적** : 시청자의 반론을 선점하고, 예상 못 한 결정타로 뒤집는다

**공식**
```
"여기서 이렇게 생각하는 분들이 있을 겁니다.
 '[예상 반론]'
 
 맞습니다. 그 말도 틀리지 않아요.
 그런데 [재반박 — 더 강한 근거 or 의외의 시각]
 
 바로 이 점이 [예능인]을 단순한 [기존 평가]와 다르게 보는 이유입니다."
```

**예시**
```
"여기서 이렇게 생각하는 분들이 있을 겁니다.
 '정준하는 그냥 맞아주는 역할이지, 무슨 MVP냐'
 
 맞습니다. 정준하는 딜러가 아닙니다.
 그런데 생각해보세요. 딜러가 칠 대상이 없으면 어떻게 됩니까?
 탱커가 없으면 딜러는 존재할 수 없습니다.
 무한도전에서 정준하가 빠진 시즌, 프로그램이 어떻게 됐는지 기억하십니까?"
```

**핵심 포인트**
- 반론을 무시하지 말고 **먼저 인정**한 다음 뒤집는다
- 이 구간이 **댓글을 폭발**시키는 구간
- 시청자가 반박하러 댓글 달게 만드는 것이 목표

**체크포인트**
- [ ] 예상 반론을 먼저 꺼냈는가
- [ ] 반론을 인정한 뒤 더 강하게 재반박했는가
- [ ] 시청자가 댓글 달고 싶어지는 포인트가 있는가

---

## 결 (結) — 판결 / 7:00 ~ 끝

**목적** : 삼국지 장수 평가처럼 단호하게 최종 판결을 선고한다

**공식**
```
"자, 이제 판결을 내리겠습니다.

 [예능인]. 유형 [유형]형. 포지션 [포지션].
 그리고 티어는 [티어]급.
 
 [티어]급인 이유, 단 한 줄로 정리하면
 [핵심 한 줄 요약].
 
 여러분은 어떻게 생각하십니까?
 댓글로 여러분의 판결을 내려주십시오."
```

**핵심 포인트**
- 결론은 **단호하게**. 애매하게 끝내면 안 된다
- "여러분 생각은요?" 로 반드시 마무리 — 댓글 유도
- 마지막 질문이 다음 영상 소재가 되기도 함

**체크포인트**
- [ ] 유형 + 포지션 + 티어 세 가지 모두 선고했는가
- [ ] 결론이 단호한가 (애매한 표현 없는가)
- [ ] 댓글 유도 질문으로 끝났는가

---

## 전체 흐름 요약

```
기 — "다들 X라고 알고 있죠? 저는 다르게 봅니다."
승 — "이 장면을 보세요. 우리 프레임으로 보면 이렇습니다."
전 — "반론 있죠? 근데 이걸 보면 얘기가 달라집니다."
결 — "판결. [유형] / [포지션] / [티어]급. 여러분 생각은?"
```

---

## 영상 유형별 변형

### 인물 분석형 (기본)
> 기: "X는 Y급이 아닙니다" → 승: 프레임 분석 → 전: 반론 처리 → 결: 티어 선고

### 비교 대결형
> 기: "A vs B, 누가 위인가" → 승: 각각 분석 → 전: 의외의 비교 포인트 → 결: 승자 선고

### 프로그램 분석형
> 기: "이 프로그램이 레전드인 진짜 이유는 따로 있습니다" → 승: 포지션 구성 분석 → 전: "빠진 멤버가 미친 영향" → 결: "완벽한 파티 구성이었다"

### 티어표형
> 기: "2024 예능인 티어, 다시 짜봤습니다" → 승: 상위권부터 분석 → 전: "의외의 인물 상향/하향" → 결: 전체 티어표 공개
