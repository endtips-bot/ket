# 유튜브 채널 기획 요구사항 문서
> 예능인 & 예능 채널 리뷰/분석 채널

---

## 1. 채널 개요

| 항목 | 내용 |
|------|------|
| **채널 컨셉** | 예능인을 삼국지/킹덤 장수 평가 프레임으로 분석하는 리뷰 채널 |
| **운영 형태** | 부업 (본업 병행) |
| **진행 방식** | AI 음성 + 편집 (얼굴 비노출) |
| **목표 구독자** | 1년 내 10만 |
| **수익 모델** | 유튜브 광고 + 멤버십 |
| **최종 목표** | 부수입 + 인플루언서 |

---

## 2. 채널 포지셔닝

### 레퍼런스 채널
- **차도르** (격투기 리뷰) — 전문적 비평가 시각
- **김진짜** (축구 리뷰) — "왜 이강인이 국내에서 통하는가" 식 심층 분석

### 차별화 포인트
- 예능인을 삼국지 장수처럼 평가하는 독자적 프레임
- 단순 재미 평가가 아닌 **유형 + 포지션 + 티어** 3축 분석 시스템
- 비평가 입장의 객관적 분석 (팬덤 영합 없음)

### 타겟 시청자
- 주 타겟: 30~40대
- 예능을 즐기면서도 분석적으로 보고 싶은 시청자

---

## 3. 핵심 평가 시스템

### 3-1. 유형 분류 (타고난 본질)

킹덤의 장군 유형에서 차용한 분류 체계

| 유형 | 정의 | 대표 예능인 |
|------|------|-----------|
| **무력형** | 강력한 개인기 + 압도적 에너지로 분위기 장악 | 강호동, 정종철 |
| **지력형** | 꽁트/개그 설계, 판 짜는 능력, 흐름을 머리로 컨트롤 | 유재석 |
| **본능형** | 이론 없는 천부적 예능 감각, 타이밍과 직감 | 탁재훈 |

> 단일 유형 = A급 한계 / 복합 유형 = S급 조건

### 3-2. 포지션 분류 (프로그램에서의 역할)

게임 포지션 개념을 예능에 적용한 분류 체계

| 포지션 | 역할 | 대표 예능인 |
|--------|------|-----------|
| **탱커** | 맞아주고 버텨줌. 탱커 없으면 예능이 안 돌아감 | 정준하, 김종민 |
| **딜러** | 웃음 포인트를 생산하는 주공격수 | 유재석, 강호동, 탁재훈 |
| **서포터** | 판 깔아주고 다른 출연진을 살려주는 역할 | 김국진, 하하 |
| **스틸러** | 예측불가 타이밍에 기습 한 방, 장면 통째로 가져감 | 민경훈, 길, 김C |

### 3-3. 티어 분류

| 티어 | 기준 |
|------|------|
| **S** | 복합 유형 + 포지션 올라운더 수행 가능 |
| **A** | 단일 유형 장인 또는 특정 포지션 최고 수준 |
| **B** | 준수한 예능 역량, 안정적 활동 |
| **C** | 특정 상황에서만 빛나는 타입 |
| **D** | 예능 역량 부족 |

## 4. 콘텐츠 형식

### 콘텐츠 유형
- **인물 분석** — "왜 강호동이 S급 예능인인가"
- **티어표** — "2024 예능인 전체 티어 랭킹"
- **비교 분석** — "강호동 vs 유재석, 누가 더 위인가"
- **프로그램 분석** — "무한도전이 레전드인 이유 (포지션 구성으로 본다)"
- **과거 소환** — 소재 고갈 시 레전드 예능인 분석

### 영상 구조 (예시)
1. 훅 (15초) — 핵심 주장 선 제시
2. 인물/주제 소개
3. 유형 + 포지션 분석
4. 명장면 근거 제시
5. 티어 판정 및 결론

### 포맷
- 메인 영상: 5~10분
- 쇼츠: 메인 영상 하이라이트 컷 활용
- 진행: AI 음성 + 영상 편집 (얼굴 비노출)

## 5. 운영 계획

| 항목 | 내용 |
|------|------|
| **업로드 주기** | 주 1~2편 |
| **편집** | 직접 편집 (경험 있음) |
| **커버 범위** | 국내 예능 한정 (개그, 토크쇼, 리얼리티, 유튜브 예능 전체) |
| **시대 범위** | 현재 활동 중인 예능인 우선, 소재 고갈 시 과거 레전드 포함 |

## 6. 시청자 페르소나

| 페르소나 | 특성 | 시청 동기 |
|----------|------|----------|
| **김관우** | 삼국지/웹툰/게임 팬 | 좋아하는 프레임으로 예능을 분석하니 신선함 |
| **김작가** | 예능 작가/PD | 섭외 & 기획에 실질적으로 참고 |
| **이스타** | 예능 유망주 | 내 예능 포지션이 뭔지 알고 싶음 |
| **박예능** | 예능 오래 본 30~40대 | 그냥 보던 예능인데 이렇게 분석하니 새로 보임 |
